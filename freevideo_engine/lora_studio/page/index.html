◆ LoRA Studio for Eclipse
Open Eclipse

Make a LoRA of a character, an object or a style

  1. Pictures. Bring your own photos (cropped, de-duplicated, backgrounds removed for objects) or start from a description.
  2. Coverage. The image model fills the gaps: angles, close-ups, expressions, poses, places and light, all from one reference so the subject stays the same.
  3. Check. A likeness check flags pictures that drifted from the reference; regenerate them in their slot.
  4. Captions. The prompt model writes a caption per picture with your trigger word; edit any of them.
  5. Train. Train a MiniMax H3 video LoRA on this PC with ai-toolkit, or export for kohya, ai-toolkit or Musubi.
  6. Use. Link the LoRA to a cast card: writing @Name in a prompt loads it. Compare strengths in a test grid.
